How to find your laptop model number

Ordering a part for "a Dell 15-inch" is how the wrong part arrives. Every quote we give starts with the exact model, and you can find it in under a minute.

Updated 2026-09-10

Quick answer

Fastest method on Windows: press Windows+R, type cmd, then run wmic csproduct get name,identifyingnumber. That prints the model and serial. If Windows will not start, look at the sticker on the underside or inside the battery bay. Dell calls it a Service Tag, HP a Product Number, Lenovo a Machine Type Model.

On the laptop itself

  • Underside sticker: model, product number and serial. Often under the stand or near the vents.
  • Battery bay: on older laptops with removable batteries, the label is often inside.
  • Under the base cover: some thin laptops print it inside; we can read it when it is in for a check.
  • Screen bezel or palmrest: usually only the family name (for example "Inspiron 15"), which is not enough to order parts.

From Windows, in one command

  • Command Prompt: wmic csproduct get name,identifyingnumber prints the model and serial.
  • Or run msinfo32 and read System Model and System SKU.
  • PowerShell alternative: Get-CimInstance Win32_ComputerSystem | Select Model.

Screenshot whichever you use and send it to us on WhatsApp; that is enough for us to identify the part.

Brand by brand

  • HP: Product Number (for example 8VZ42PA). The support site identifies the exact configuration from it. HP repairs.
  • Dell: Service Tag, seven characters. It maps to the exact build. Dell repairs.
  • Lenovo: Machine Type Model (for example 82XQ). ThinkPads also print the type on the bezel. Lenovo repairs.
  • ASUS: model code on the underside (for example X515EA). ASUS repairs.
  • Acer: model plus SNID on the underside. Acer repairs.

Why it matters for the part

Two laptops with the same marketing name can take different panels, different keyboards and different batteries depending on the configuration and the factory. The model and serial let us confirm the panel connector, the battery part number and the keyboard layout before ordering, so the part fits the first time.

Questions people ask

Before you decide

How do I find my laptop model without turning it on?

The sticker on the underside, or inside the battery bay on older models. That is exactly what we do when a laptop arrives dead.

How do I check my laptop model in cmd?

wmic csproduct get name,identifyingnumber. On newer Windows builds, Get-CimInstance Win32_ComputerSystem | Select Model in PowerShell.

How do I find the year my laptop was made?

The serial usually encodes it, and the maker's support page shows the warranty start date, which is close to the manufacturing date.
